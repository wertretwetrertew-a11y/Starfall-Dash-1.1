# Starfall Dash — Auto Update

Этот updater держит локальную копию игры синхронизированной с GitHub.

## Первый запуск

1. Один раз клонируй репозиторий:
   `git clone https://github.com/wertretwetrertew-a11y/Starfall-Dash-1.1.git`
2. Положи/оставь репозиторий в обычной папке на компьютере.
3. Запусти `Start-Auto-Updater.bat`.
4. Updater будет проверять GitHub каждые 15 секунд.

## Как это работает

- если новых коммитов нет — ничего не меняет;
- если в GitHub появился новый коммит — автоматически делает `git pull --ff-only`;
- если в локальной папке есть несохранённые изменения — обновление пропускается, чтобы их не затереть;
- игра всегда остаётся в одной и той же папке, поэтому старую версию удалять и заново скачивать не нужно.

## Важно

Updater синхронизирует файлы репозитория. Он не запускает игру автоматически.
